# H3 电影镜头

> **状态程序：** 镜头句里的动作按「当前状态 + 动作 = 新状态」逐步写；行为与状态不得冲突，见 `vibe-prompting` 规则 2.1。本 skill 只管景别、机位、运镜这些镜头句式。

字段顺序、参考图标签和时间戳写法遵循 `h3-prompt-writing`（**声明先于入画**：写 `[Shot 1]` 动作前先保证本镜 Subject 已定义，见该 skill）。本 skill 只规定镜头句怎么写（景别、机位、焦段、运镜），字段与声明见 `h3-prompt-writing`。

## 已验证的经验

严禁在 `reference generation` 中加上「几秒」这种时间描述词，否则整段会被识别为音频。时间只出现在切镜点：`[Shot 1]` 不加时间戳，后续镜头写成 `[Shot N] At MM:SS.mmm`。单镜头内的动作按先后写成连续叙述。

后面出现在镜头里的一切（含肩、手、背）本镜必须有 `subject_definitions` 声明（有图则上传，无图则文字声明）；硬切不继承上一镜声明。局部入画用肯定句「构图仅含 Subject 的×」；正文不用「不是/无/没有」（见 `h3-prompt-writing` 肯定赋值）。

## 运镜

一条提示词里放的是一套镜头组合，不是一个运镜词。组合按这个顺序写死：景别，机位，焦段，镜头始终锁定谁，主体停在画面中心或黄金分割点，最后才是主运镜。框架先固定，运镜是加在框架上的动作。只写 `Push In`、不写锁定谁，焦点会自己换人，机位会乱跑。

直接使用这些名称：

| 名称 | 动作 | 用来做什么 |
| --- | --- | --- |
| Push In | 向前逼近 | 聚焦情绪、压迫 |
| Pull Out | 向后拉开 | 揭示环境、孤独 |
| Pan | 水平左右摇 | 环视、搜寻 |
| Tilt | 上下摇 | 仰拍显强，俯拍显小 |
| Arc | 绕主体弧形转动 | 对峙、史诗感 |
| Tracking | 与人物同步移动，距离不变 | 跟随、代入 |
| Static | 机位不动 | 对峙、沉重情绪 |
| Slight Shake | 轻微手持 | 纪实、追逐、紧张 |

每条主运镜写全三样：**运动类型 + 速度（slow / medium / fast）+ 幅度（small / medium / large amplitude）**。环绕要带上绕多远，只写「环绕」时，机器会绕很大一圈或者猛转。

一个镜头组合只有一种主运镜。推、摇、环绕叠在一起，模型拆不开。二级运动只允许极轻的 Slight Shake，而且幅度是 small。特写只配 Push In, slow, small amplitude，不配大范围 Arc。

焦段跟着景别：全景 24mm 或 35mm，中景和半身 50mm，近景和特写 85mm。

```text
中景。平视，50mm。镜头始终锁定他的脸，脸停在画面中心。他看着她。Push In, slow, small amplitude。
```

不要写「镜头推进，电影感，很震撼」。空泛形容词 H3 认不准。

镜头漂移靠这套框架压住。提示词正文里不写「无规则晃动、镜头漂移、机位随机跳转、焦点乱跑、主体移出画面、剧烈无规则运动」。

一段生成里，一镜到底只用一个镜头组合。这段本身是硬切多镜时，最多三个组合，每个组合至少三秒，秒数写在提示词外面。切到下一个组合时核对轴线，人物的左右和视线留在轴线同一侧。骑乘和飞行仍最多两个组合，用全景或中景。

## 时长

一次生成是 4 到 15 秒的整数。秒数按这一下动作自然做完来定，写在提示词外面的分段标题里，不写进 `reference generation`。

多出大约一秒，空档里会冒出没有写过的说话。少大约一秒，身体会不合常理地变形。台词按一口气能说完来给秒数，动作按做完那一下来给秒数，不要为了凑时长加停顿。

## 一镜到底

一条长镜头拆成几段生成，每段仍是一种运镜，成片上看起来不切。

第一段定机位、方向和人物起点。后面每段用上一段成片的最后 22 帧做引导上端，这 22 帧不占本段时长；**上端即本段初始状态绑定**，提示词从停住处只写新动作。`retention_analysis` 勿强绑与上端不符的「当前状态」，否则接点切镜。上一镜做过的动作再写一遍，接点会重演。硬切与初态申明见 `h3-prompt-writing`。

换景、换机位、正反打另开一段，硬切，不写引导。换景要藏进动作、轮廓、遮挡或门洞里时，用「转场」那一节，仍是一段生成、一种主运镜。长镜头这一段里不再开 `[Shot 2]`，小的景别变化用同一种运镜完成。

## 3D导演台

在 3D 导演台里摆人，一律用圆柱体或长方体代替人形。人形白模会跟着导出的参考帧进视频。

环绕、跟拍、斗篷擦镜、摄像机穿过门洞，先在导演台做关键帧，导出运动参考。文本只锁景别、焦段、主体位置、触发的那一瞬和这一种运镜。简单的推、拉、摇、静止，直接把镜头组合写进提示词。

## 转场

转场是一段生成里的换景，不是硬切。每条写清四项：在哪一瞬间切换，前后什么保持不变，摄像机怎么动，风格写成写实真人、24fps、物理电影镜头。正文里不写「禁止卡通」。

1. 动作匹配。同一个动作的轨迹、发力方向和速度不变，在动作顶点换成另一个场景或另一个人。用来做回忆、身份切换、从现实进入幻境。这一下只留一个清楚的肢体动作，四肢轨迹分开。
2. 形状匹配。前后两个物体的轮廓对齐，用这个形状接过去。折扇的弧接远山的脊，圆形光团接圆月。靠物体本身的轮廓，不靠大块发光。
3. 环境重塑。机位、构图、人物位置不动，只变天气、季节和光。用 Static。适合等待、打坐、时间流逝。
4. 前景遮挡。树干、石门、斗篷、雨水或雾气滑入画面，盖满镜头的一瞬换成新场景，遮挡物移开时人已经在新地方。写实换景优先用这一种。遮挡动画可以在导演台做。
5. 穿过边界。摄像机穿过门洞、山洞、格栅或水帘，边界盖住画面的一瞬换成另一侧的世界。摄像机关键帧在导演台做。
6. 甩镜。镜头快速横摇，运动模糊最满的一瞬换成新场景。适合突袭和紧急跳转。写实场面幅度停在 medium，脸在模糊里的时间短。

```text
中景。平视，50mm。镜头始终锁定挥出的拳头，拳头停在画面中心。修士一拳挥到顶点，拳的轨迹、发力方向和速度保持原样，顶点这一瞬庭院换成幻境。写实真人，24fps，物理电影镜头。Push In, slow, small amplitude。
```

```text
全景。平视，35mm。镜头始终锁定庭院中央的人，人停在画面黄金分割点。机位、构图和人的位置保持不动。天色从黄昏沉到深夜，草木换了一轮。写实真人，24fps，物理电影镜头。Static, slow, small amplitude。
```

```text
中景。平视，50mm。镜头始终锁定修士。斗篷从镜头前扫过，布料盖满画面的一瞬，移开之后人已经站在山洞里。写实真人，24fps，物理电影镜头。Tracking, medium, small amplitude。
```

```text
中景。平视，35mm。镜头始终锁定向前的石门。摄像机穿过门洞，门框盖住画面的一瞬，门外的庭院换成门内的秘境。写实真人，24fps，物理电影镜头。Tracking, medium, small amplitude。
```

```text
全景。平视，50mm。镜头始终锁定那道弧，弧停在画面中心。打开的折扇停住，扇面的弧对准远山的山脊，轮廓对齐的一瞬从扇面进入远山。写实真人，24fps，物理电影镜头。Static, slow, small amplitude。
```

```text
中景。平视，35mm。镜头始终锁定被袭击的人，人停在画面中心。镜头快速横摇，运动模糊最满的一瞬，巷子换成室内。写实真人，24fps，物理电影镜头，180 度快门。Pan, fast, medium amplitude。
```

## 皮肤和光

写实文戏的皮肤写成：哑光，自然次表面散射，细微毛孔，高光柔和并收在颧骨边缘一条窄线上，自然漫反射，胶片颗粒，皮肤留着细微肌理。

提示词里不出现 shiny、glossy、镜面反光、强烈 bloom、抛光、通透发光皮肤。Octane、path tracer 这类渲染词会加重全局反射，人脸和文戏不用。爆炸远离人脸时可以写 OctaneX。

一段只写这一镜看得见的变化。对白特写不要同时堆角色细节、环境、特效、Field、Contact、运镜、灯光、渲染器和氛围词。堆满之后，模型会先做大面积高光，皮肤出油。Contact 只在身体贴着身体时写。Field 只在这一镜真有能量时写。

灯光先写光源在哪。轮廓光停在颧骨边缘，暗部留着毛孔和纹理。

```text
中近景。平视，85mm。镜头始终锁定她的脸，脸停在画面中心。侧自然光，轮廓光停在颧骨边缘一条窄线上，暗部留着毛孔。哑光皮肤，细微毛孔，自然次表面散射，胶片颗粒。Static, slow, small amplitude。
```

启用 `Field力场扰动模拟` 时，在力场句子后面加上：力场的光停在能量区域，皮肤保持哑光，颧骨上的高光仍是原来那一条窄线。

ComfyUI 第二次高清重绘会把第一遍的油光放大。肥猴 REMIX 能压人脸油光，只用于静止或慢节奏的文戏特写。打斗、骑乘、飞行仍用原来的模型。

## 特效

不要把冲击波、魔法光写成贴在画面上的发光层。特效出现时，空气、物体和光必须一起受力。

关键词 `Field力场扰动模拟` 放在特效描述的前面。只写这四个字不够，后面必须写力场引起的连锁反应，按时间写成扩散、增强、衰减。一段里只留一种能量。

四层都要落到看得见的变化：

1. 空气：折射、热浪、色散，空间出现波纹。
2. 物体：风压吹动发丝、布料、植被，近处的东西被挤压或掀起。
3. 光影：整个场景的颜色跟着特效变，能量强则亮，衰减则暗。
4. 粒子：烟、雾、尘顺着湍流流走，不悬在原地。

质感用具体器材名，不用「电影感」。魔法靠近皮肤时用 ARRI Alexa，并写上哑光皮肤。爆炸远离人脸时用 OctaneX。需要引擎光时写 UE5.4。

```text
中近景。平视，50mm。镜头始终锁定施法的人。Field力场扰动模拟。魔法能量先从身体向外扩散，空气出现热浪和折射，紫光把周围的颜色带偏。力场的光停在能量区域，皮肤保持哑光，颧骨上的高光仍是原来那一条窄线。风压接着掀起布料和发丝，体积粒子顺着气流滚出去。能量减弱时，阴影一起暗下来。ARRI Alexa，胶片颗粒。Push In, slow, small amplitude。
```

```text
全景。Field力场扰动模拟。冲击波从爆点向外推，近处空气先被压弯，植被和布料随风压变形。强光穿过这层空气产生色散，烟尘被卷着走。波前过去之后，橙红光一起变暗。OctaneX。Slight Shake, fast, small amplitude。
```

```text
全景。Field力场扰动模拟。地热贴着地面持续扰动，近地面空气一直扭曲，热气向上翻。远处轮廓被折射拉偏，悬浮热雾顺着上升气流走，暖调光随热浪强弱一起变。Static, slow, small amplitude。
```

## 接触

骑手悬在坐骑上方、腿不贴身体，是接触没算。关键词 `Contact碰撞接触计算` 放在主体描述前面，强制计算接触面的受力。

两层都要看见：

1. 贴合：臀部和腿顺着坐骑的曲面贴住，不悬空。
2. 形变：坐骑跑或飞时，骑手跟着起伏、身体随颠簸晃；皮毛和肌肉被体重轻轻压出凹陷。

和力场联用时按这个顺序：景别，Contact，人和坐骑怎么贴，Field，气流尘土和衣摆发丝，最后是器材名和运镜。写实玄幻把重量、挤压、尘土、被风压吹动的布料和头发写清楚，不写大块体积发光。

骑乘和飞行是强动态。一段里最多两个镜头，优先全景或中景。近景特写容易腿穿进身体、关节拧转。

```text
全景。Contact碰撞接触计算。骑手贴在暗翼魔龙背上，体重把鳞片和皮肉压出一块凹陷，腿夹住龙身，身体随着翅膀的起伏晃。Field力场扰动模拟。翅膀扇起的气流卷起烟尘，风压把下面的草木压弯，翼尖带起热浪和折射，光跟着翅膀的扇动变亮变暗，尘粒顺着气流走。ARRI Alexa。Tracking, medium, large amplitude。
```

```text
中景。Contact碰撞接触计算。骑手夹住巨兽的躯干，臀部贴着背，体重把皮毛压陷，身体随着步伐一起一伏。Field力场扰动模拟。四蹄掀起尘土，气流掀起衣摆和长发，近处草叶倒向一边，贴地的空气轻轻颤。自然光，胶片颗粒。Tracking, medium, small amplitude。
```

## 看不见的部位

成片认的是看得见的粗状态。这一镜里看不见的机关不要写，模型会把它画出来。

手不在画里时，只写能看见的粗姿势，例如「双手背在身后」。这句不写，手会自己乱摆。手上或手腕上的道具（绳子、手环、包带）这一镜看不到就不写，写了道具会被画进画面、穿进身体或跑到错误位置。

脚上、背后的道具同理，这一镜看不到就只留姿势。下一镜那个部位入画了，再写道具。

## 声音

要说的话只放进 `<d>[Chinese] …</d>`。身份和语气写在标签外面。声景只写环境声、动作声、呼吸，不复述台词。谁说话由谁拿 `<d>` 决定，不写「没有人说话」。有画外声时，听众的嘴唇闭着只在 `retention_analysis` 写一次，镜头句里不写嘴唇（见 `h3-prompt-writing`「简洁」）。

同一镜里两段台词接在一起时，`</d>` 和下一段 `<d>` 之间只留下一位说话人的身份和语气。不插动词，不插「点头」「停一下」这类动作。插进去的动词会被当成台词读出来。

两人各说一句时，第二句重新写这位说话人的身份和语气，动词只用「说」。不用「接着说」「继续说」。这两个词会把第二句接回前一个人，画外音切不过去。

严禁在 `summary` 中写「说」以及「说」的同义词，否则生成时会把后面的文字变成语言。

```text
他用平稳的男声（S1）说：<d>[Chinese] 车到了吗？ </d>画外低男声（S2）说：<d>[Chinese] 还在路上，十分钟就到。 </d>
```

这一段没有配乐时，`non_diegetic_music` 写 `none` 或 `无`。不要写成「没有音乐」「不要配乐」「禁止音乐」。

## 发布前检查项（平台 UI 约束，不是 H3 模型规则）

发到短视频频道的视频，画面必须铺满到右边缘。右侧约 1/20 的那一条不能长时间留白，更不能是白底；否则点赞、评论、转发的白色图标落在空白上看不见。
