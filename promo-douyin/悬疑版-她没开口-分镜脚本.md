# 悬疑版推广片《她没开口》· 文案 + 分镜

**规格：** 竖屏 9:16，1080×1920，**1:55**，30fps 剪辑  
**配音：** 你自己录（下文「旁白」列）。画面字只放关键句，不逐字上字幕也成立。  
**切入：** 一条生成视频里，画面中的人嘴唇闭着，音轨里却有人说「你来晚了」。  
**结构：** 冷开场 → 不是第一次 → 排查 → 真相 → 复现 → 删掉那一个字  
**混搭：** H3 生成流（证据片）+ 截图流（播放器、编辑器）+ HTML 流（波形、证据板、代码）+ three.js 3D 流（提示词走廊）

## 一、视觉与声音统一规则

| 项 | 规定 |
| --- | --- |
| 底色 | 近黑蓝 `#0B0D12`，所有 HTML / 3D 场景共用 |
| 主文字 | 冷白 `#E8E6E3`，标题用**思源宋体 Heavy**（悬疑感），代码用 **JetBrains Mono** |
| 唯一强调色 | 信号红 `#FF3B30`，**全片只给「说」字、波形尖峰、证据板红线用**。别处一律不用红 |
| 证据片质感 | H3 片段统一加：2% 颗粒、轻暗角、左上角小号时间码 `EVIDENCE 0X · 02:14 AM` |
| 转场 | 全片只用三种：硬切、黑场、「同形状匹配」（波形尖峰 ↔ 红字 ↔ 红线）。不用花式转场 |
| BGM | 前 70 秒**不要旋律**，只有低频 drone + 雨声 + 房间底噪；真相段（1:12 起）才进一条极简钢琴/合成器脉冲；1:38 复现段全部撤掉 |
| 静音 | 片中有三处刻意的完全静音（标 🔇），是悬疑的主要来源，剪的时候别填 |

**旁白语气：** 像深夜跟朋友讲一件刚碰到的怪事。音量低，语速慢，句号处停半拍。不要播音腔，不要「家人们」，不要往上扬的结尾。

## 四、H3 证据片提示词（四条）

先用文生图出两张图，四条共用，保证是同一个人、同一张桌：

- **Picture 1**：年轻女性，黑色齐肩短发，深灰色高领毛衣，正面半身，暖色台灯侧光
- **Picture 2**：夜间咖啡馆靠窗座位空景，窗外下雨，木桌上一盏暖色小台灯

E1–E3 是**故意写错**的证据片，每条建议跑 3–5 次挑最「出事」的一条。E1 如果几次都没念出那句话，就自己找一个人录「你来晚了」，压低通、加一点房间混响后贴在 3 秒处。
