## 段 2 · 怎么写（即兴讲解 · 只记对应关系）

### Ref2VA 六段 ≈ 写程序

| H3 字段 | 可当什么理解 | 你讲的时候可以点 |
| --- | --- | --- |
| `subject_definitions` | **声明 / import** | 本段画里会出现的 `<Subject>` 先在这里定义；有图上传，无图文字声明 |
| `retention_analysis` | **初值赋值**（0 秒状态） | 「当前状态：…」= 这一镜开头看得见什么 |
| `summary` | **注释**（不参与主逻辑） | 概括画面；**不要「说」及同义词** → 否则后面易被当台词执行 |
| `detailed_description` · `[Shot 1]` | **主程序** | 从同一初值复述起笔，再 **一步一改**；`S₁ = S₀ + a₁` |
| `overall_soundscape` | 环境音 I/O | 脚步、杯声等 |
| `non_diegetic_music` | 配乐开关 | `none` |

基础模式（T2VA / I2VA 等）没有六段：逻辑一样，初值在 `[Shot 1]` 开头（I2VA 首帧图 = 最强初值）。

---

### 现象 ↔ 先查哪

| 观众能感知到的 | 优先查 | 典型错法 |
| --- | --- | --- |
| **莫名多一句台词 / 幻听** | `summary`、运镜句里是否误写「说」 | `她说：……` 写在 summary |
| **乱入的人、手、换脸** | 本段 `subject_definitions` | 正文写了 `<Subject N>` / 「一只手」但未 declare |
| **动作跳、重复、双杯** | 初值 vs 动作是否打架 | retention 里已有杯，`[Shot 1]` 又写放杯 |
| **硬切接不上** | 新段是否重新声明 + 写全初态 | 以为继承上一段变量 |
| **有引导还切镜** | 引导段初态是否与上端末帧一致 | retention 强绑了与引导冲突的姿势 |

---

### 推荐讲解顺序（画面自选，无口播稿）

1. **总论**：H3 是固定字段顺序 → 像跑程序，不是散文（可录 `fields-map.html` / README 表 / 手画六格）  
2. **对照 1**：`summary` + 「说」→ `code-intro.html` 第一幕（或编辑器里标红一行）  
3. **对照 2**：未声明 Subject → `code-intro` 第二幕 / ReferenceError 示意  
4. **对照 3**：状态 + 动作 → `code-intro` S0+a1 / 或 E1 错 vs **E4** 对（各几秒）  
5. **收束一句**：声明 → 当前状态 → 一步一改（可闪 `pipeline.html` 或三词字卡）

**可用录屏素材（非必须全用）：** `code-intro.html` · 待做 `fields-map.html` / `pipeline.html` · 仓库 `skills/` 目录树

## H3 素材（两条够用）

| 片 | 用途 |
| --- | --- |
| **E1** | 开头；summary 故意含「她说：你来晚了」 |
| **E4** | 讲解对照；正确声明 + 放杯一步 |

### E1

```text
subject_definitions:
<Subject 1> 是来自 <Picture 1> 的年轻女性客人。
<Subject 2> 是来自 <Picture 2> 的咖啡馆靠窗座位。

summary:
[reference generation] <Subject 1> 坐在 <Subject 2> 靠窗桌边。她说：你来晚了。

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - 外观按 <Picture 1>。当前状态：她坐在靠窗桌边，双手放在桌面。
<Subject 2> (appears in [Shot 1]): fully_preserved - 场景按 <Picture 2>。

detailed_description:
写实真人，24帧，物理电影镜头。竖屏构图。
[Shot 1] 中景。平视，50mm。镜头锁定<Subject 1>。她坐在靠窗桌边，双手放在桌面。Static, slow, small amplitude.

overall_soundscape:
咖啡店环境底噪。

non_diegetic_music:
none
```

### E4

```text
subject_definitions:
<Subject 1> 是来自 <Picture 1> 的年轻女性客人。
<Subject 2> 是来自 <Picture 2> 的咖啡馆靠窗座位。
<Subject 3> 是服务员。本段仅双手与小臂入画。

summary:
[reference generation] <Subject 3> 的双手给 <Subject 1> 放下一杯咖啡。

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - 外观按 <Picture 1>。当前状态：她坐在靠窗桌边，双手放在膝上。
<Subject 2> (appears in [Shot 1]): fully_preserved - 场景按 <Picture 2>。当前状态：桌面无杯。
<Subject 3> (appears in [Shot 1]): weak_reference - 文字声明。当前状态：双手与小臂在画面右侧，托着白瓷杯。

detailed_description:
写实真人，24帧，物理电影镜头。竖屏构图。
[Shot 1] 中景。平视，50mm。镜头锁定<Subject 1>。她坐在靠窗桌边，双手放在膝上。<Subject 3>的双手把杯子放到她面前，杯底轻触桌面，双手移出画外。Static, slow, small amplitude.

overall_soundscape:
杯底轻触桌面。

non_diegetic_music:
none
```

E1 不出多余台词时，剪辑里 **贴一句「你来晚了」** 即可。
