## 三、各制作方式操作要点

### 1. HTML + 代码动画（`code-intro.html`）

1. Chrome 打开 `code-intro.html`，F11 全屏或窗口裁成 9:16。  
2. OBS / 系统录屏 **60fps**，播一遍约 18s（含三幕）；按 **R** 可重播。  
3. 剪映里调色：略提对比，加 5% 颗粒可选。

### 2. 定格漫

- 打印或平板展示 `assets/定格卡片文案.md` 五张。  
- 每张 **0.8–1.2s**，手翻或跳切；可加「啪」的切镜声。  
- 光线统一，背景纯黑或灰墙。

### 3. 文字跳入

- 剪映：字幕模板「打字机 / 弹跳 / 逐字」；关键字：**未声明、S0、当前状态、硬切、引导**。  
- 与录屏层分轨，字在 safe area 内，**避开右侧 5%**。

### 4. MiniMax H3

- 严格用 `H3-片段提示词.md` 通用六段，竖屏生成若平台支持选 9:16；否则 16:9 生成后中心裁切竖屏。  
- 对比镜头（可选第三支）：故意 **summary 写「她说」** 的错误版 4s，仅内部对比不发布，用来提醒自己差异。

### 5. 混搭剪辑顺序（剪映轨）

```
V1 主画面（H3 + 定格 + HTML 录屏）
V2 字幕 / 跳入字
V3 B-roll（Cursor 目录、Comfy 提交界面 各 1–2s，无项目路径入镜）
A1 BGM
A2 音效（切镜、键盘）
```
