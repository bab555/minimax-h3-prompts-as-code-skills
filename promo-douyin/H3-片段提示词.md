## 镜头 A · 4s · 硬切 · 放杯（对比「稳」）

上传：无参考图可走 T2VA；有图则 Picture1=女主、Picture2=场景。

```text
subject_definitions:
<Subject 1> 是坐在靠窗桌边的女性客人。
<Subject 2> 是咖啡店服务员。本段仅双手与小臂入画。

summary:
[reference generation] 靠窗桌边有一只空杯。

retention_analysis:
<Subject 1> (appears in [Shot 1]): weak_reference - 文字声明。当前状态：她坐在靠窗桌边，双手放在桌面。
<Subject 2> (appears in [Shot 1]): weak_reference - 文字声明。当前状态：双手与小臂在画面右侧，托着托盘，悬在桌面上方。

detailed_description:
写实真人，24帧，物理电影镜头。
[Shot 1] 本镜画面人物仅<Subject 1>的上半身与<Subject 2>的小臂。中景。平视，50mm。镜头始终锁定<Subject 1>，她在画面中心。她坐在靠窗桌边，双手放在桌面。靠窗桌边有一只空杯。<Subject 2>的双手与小臂在画面右侧，托着托盘，悬在桌面上方。<Subject 2>的双手与小臂入画，把杯子放到她面前的桌面，杯底轻触桌面。她仍坐在原处。画面右缘是窗框。Static, slow, small amplitude.

overall_soundscape:
杯底轻触桌面。咖啡店环境底噪。

non_diegetic_music:
none
```

## 镜头 B · 6s · 硬切 · 离席（状态链）

```text
subject_definitions:
<Subject 1> 是坐在靠窗桌边的女性客人。

summary:
[reference generation] 靠窗的桌与门在画面右侧。

retention_analysis:
<Subject 1> (appears in [Shot 1]): weak_reference - 文字声明。当前状态：她坐在靠窗桌边，双脚平放在地面，双手放在膝上。

detailed_description:
写实真人，24帧，物理电影镜头。
[Shot 1] 中景。平视，50mm。镜头始终锁定<Subject 1>，她在画面中心。她坐在靠窗桌边，双脚平放在地面，双手放在膝上。她双手撑桌站起来，站在桌边。她转身面向画面右侧的门，走向门口，停在门前。画面右缘是门框。Pan, slow, small amplitude.

overall_soundscape:
椅子轻响。脚步。

non_diegetic_music:
none
```

## 镜头 C · 4s · 可选 Hook · 乱入感（T2VA）

用于片头 0:00–0:03「问题感」；若不喜欢负面演示可改实拍空镜。

```text
integrated_multimodal_description:
[Shot 1] 竖屏构图。中景。平视，35mm。镜头锁定靠窗空桌。写实咖啡馆，柔和日光。桌面干净，无人物。0.5秒后画面右侧边缘出现一张模糊的侧脸，占画面不到五分之一，一秒内又移出画外。桌面仍空。无人物开口。画面右缘是窗框。Static, slow, small amplitude.

overall_soundscape:
咖啡店环境底噪。

non_diegetic_music:
none
```

## 错误示范（勿发布 · 仅 A/B 对比自测）

summary 故意踩雷：

```text
summary:
[reference generation] 她说这杯咖啡很好。
```

同一 `detailed_description` 再生成一条，对比幻听差异。
